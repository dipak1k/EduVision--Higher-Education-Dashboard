# EduVision — Atlas of Higher Education

EduVision is an end-to-end data analytics project that explores the global
higher-education landscape. It covers the full workflow: collecting and cleaning
data, analyzing it with SQL, building reports in Power BI, and presenting the
results in an interactive HTML dashboard.

## Tools Used

| Tool | Purpose |
|------|---------|
| **Python** | Data cleaning, transformation and exploratory analysis |
| **Excel** | Initial data preparation, quick checks and pivot summaries |
| **SQL** | Querying and aggregating data (rankings, trends, comparisons) |
| **Power BI** | Interactive reports, DAX measures and visualizations |
| **HTML/CSS/JS** | Standalone dashboard for sharing and live demo |

## Dashboard Sections

- **University Overview** – Top universities by QS rank, universities by region,
  top fields of study, and growth trends.
- **Research Analytics** – Publications over time, by subject area, top
  institutions and top cited papers.
- **Student Analytics** – Students by level of study, international student
  trends and top countries of origin.
- **Country Comparison** – Side-by-side country comparison and overall score
  rankings.

## Project Workflow

1. **Data collection** – Gather higher-education datasets (rankings, research, student data)
2. **Data cleaning** – Handle missing values, duplicates and formats using Python (Pandas) and Excel
3. **Data analysis** – Write SQL queries to extract insights
4. **Visualization** – Build interactive reports in Power BI
5. **Presentation** – Publish the final dashboard as an HTML page

## Run the Dashboard

Open `eduvision_dashboard.html` (or `index.html`) in any modern browser. No installation needed.
